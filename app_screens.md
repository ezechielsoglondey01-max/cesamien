
# Application mobile destinée aux étudiants

## Écran 1 — Accueil

L'écran d'accueil présente :

- les événements à venir ;
- les annonces importantes ;
- les événements de la CESAM Centrale ;
- les événements de la CESAM de la ville ;
- les événements des communautés suivies ;
- des recommandations de communautés ;
- un accès rapide au guide.

> **Objectif :** donner à l'étudiant les informations importantes dès l'ouverture de l'application.

## Écran 2 — Explorer

Cette page permet de découvrir :

- des communautés ;
- des étudiants ;
- des événements ;
- des informations utiles.

**Filtres possibles :**

- ville ;
- domaine ;
- communauté ;
- type d'événement.

## Écran 3 — Guide

Le guide est organisé par ville et par catégorie. Pour la ville d'Agadir, les catégories peuvent inclure :

- Administratif
- Études
- Transport
- Santé
- Vie quotidienne
- Sécurité
- Opportunités

Chaque information peut contenir :

- un titre et une description ;
- une adresse et une localisation ;
- des horaires ;
- les documents nécessaires ;
- des conseils ;
- une source ;
- une date de mise à jour.

## Écran 4 — Marketplace étudiant

Cette page permet aux étudiants de publier et de consulter des annonces concernant :

- l'achat et la vente d'objets ;
- l'échange de biens ;
- les services proposés par les étudiants ;
- le logement et la colocation ;
- le matériel et les fournitures étudiantes.

**Filtres possibles :**

- ville ;
- catégorie ;
- type d'annonce ;
- prix.

Chaque annonce peut contenir :

- un titre et une description ;
- des photos ;
- un prix ou des modalités d'échange ;
- une ville et une localisation ;
- des coordonnées ou une messagerie intégrée ;
- une date de publication.

## Écran 5 — Profil

Le profil contient :

- les informations personnelles ;
- l'établissement ;
- la ville ;
- les centres d'intérêt ;
- les communautés suivies ;
- les paramètres ;
- les notifications.
