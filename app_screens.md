
### APPLICATION MOBILE DESTINES AUX ETUDIANTS

> PAGE 1 : ACCUEIL

* événements à venir ;
* annonces importantes ;
* événements CESAM Centrale ;
* événements CESAM de la ville ;
* événements des communautés suivies ;
* recommandations de communautés ;
* accès rapide au guide.

Objectif :

Donner à l'étudiant toutes les informations importantes dès
l'ouverture de l'application.

> PAGE 2 — EXPLORER

Cette page permet de découvrir :

* communautés ;
* étudiants ;
* événements ;
* informations utiles.

Filtres possibles :
* ville ;
* domaine ;
* communauté ;
* type d'événement.

> PAGE 3 — GUIDE

Le guide est organisé par ville et catégories.

Exemple :

```
AGADIR

[ Administratif ]
[ Études ]
[ Transport ]
[ Santé ]
[ Vie quotidienne ]
[ Sécurité ]
[ Opportunités ]
```

Chaque information peut contenir :

* titre ;
* description ;
* adresse ;
* horaires ;
* localisation ;
* documents nécessaires ;
* conseils ;
* source ;
* date de mise à jour.

> PAGE 4 — MARKETPLACE ÉTUDIANT

Cette page permet aux étudiants de publier et de consulter des annonces :

* vente et achat d'objets ;
* échange de biens ;
* services proposés par les étudiants ;
* logement et colocation ;
* matériel et fournitures étudiantes.

Filtres possibles :
* ville ;
* catégorie ;
* type d'annonce ;
* prix.

Chaque annonce peut contenir :

* titre et description ;
* photos ;
* prix ou modalités d'échange ;
* ville et localisation ;
* coordonnées ou messagerie intégrée ;
* date de publication.

> PAGE 5 — PROFIL

Contient :

* informations personnelles ;
* établissement ;
* ville ;
* centres d'intérêt ;
* communautés suivies ;
* paramètres ;
* notifications.
