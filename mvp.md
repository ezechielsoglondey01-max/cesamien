
###  MVP POUR LE HACKATHON

L'objectif du hackathon n'est pas de développer immédiatement
toutes les fonctionnalités.

Le MVP doit démontrer clairement la valeur du concept.

> FONCTIONNALITÉS À IMPLÉMENTER EN PRIORITÉ :

1. Création du profil étudiant

2. Guide étudiant d'une ville

3. Liste des communautés

5. Abonnement à une communauté

6. Fil d'événements personnalisé

7. Création/publication d'un événement par une communauté

8. Assistant IA basé sur les informations du guide

9. Interface CESAM permettant de gérer les contenus

10. Marketplace Etudiant

> FONCTIONNALITÉS À PRÉSENTER COMME ÉVOLUTION FUTURE :

* chat complet ;
* recommandations avancées ;
* carte interactive ;
* notifications push ;
* système de traduction ;
* statistiques ;
* marketplace étudiant ;
* système de mentorat ;
* vérification avancée des informations ;
* intégration avec des services universitaires.


À terme, CESAMIEN peut devenir une plateforme nationale
d'intégration et d'entraide étudiante.
