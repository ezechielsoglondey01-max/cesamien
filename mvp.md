
# MVP pour le hackathon

L'objectif du hackathon n'est pas de développer immédiatement toutes les fonctionnalités. Le MVP doit démontrer clairement la valeur du concept.

## Fonctionnalités prioritaires

1. Création d'un profil étudiant
2. Guide étudiant d'une ville
3. Liste des communautés
4. Abonnement à une communauté
5. Fil d'événements personnalisé
6. Création et publication d'événements par une communauté
7. Assistant IA basé sur les informations du guide
8. Interface CESAM permettant de gérer les contenus
9. Marketplace étudiante

## Évolutions futures

Les fonctionnalités suivantes pourront être développées dans une prochaine phase :

- chat complet ;
- recommandations avancées ;
- carte interactive ;
- notifications push ;
- système de traduction ;
- statistiques ;
- système de mentorat ;
- vérification avancée des informations ;
- intégration avec des services universitaires.

## Vision à terme

À terme, CESAMIEN peut devenir une plateforme nationale d'intégration et d'entraide étudiante.
